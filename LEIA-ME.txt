CONTROLE CORREIOS ITU - TOTVS
=============================

Monta a Tabela Controle Correios Itu - TOTVS de cada dia a partir do relatorio
DadosEntregues do TOTVS e guarda um historico com cliente e status de cada envio.

INSTALAR E ABRIR
----------------
Rode "Instalar Controle Correios Itu.exe" (pasta instalador do GitHub). Nao pede
administrador; cria o atalho "Controle Correios Itu" na Area de Trabalho e no Menu Iniciar.
O programa abre numa janela do Chrome. Para sair, feche a janela ou clique em "Fechar programa".
Para desinstalar: Configuracoes > Aplicativos > Controle Correios Itu.

Na primeira vez o Windows pode avisar "O Windows protegeu o computador":
clique em "Mais informacoes" e "Executar assim mesmo".

ATUALIZACAO
-----------
Toda vez que abre, o programa ve no GitHub se tem versao nova. Se tiver, aparece a faixa
verde "Versao nova disponivel": clique em "Atualizar agora" e ele fecha, instala e abre
de novo sozinho. A pasta dos dados e as configuracoes continuam iguais.

USO DO DIA A DIA
----------------
1. Tire o relatorio DadosEntregues no TOTVS (CSV ou Excel).
2. Arraste o arquivo para a tela. So os vendedores de ITU entram; nada e duplicado.
3. A tabela do dia ja e gravada em  <pasta dos dados>\Ano\Mes\Tabela ... dia.xlsx
4. Na tabela da tela:
   - escolha o STATUS de cada envio (ou marque varios e aplique de uma vez);
   - clique no ERP, cliente ou vendedor para COPIAR;
   - no lapis ao lado do cliente voce edita o nome; no lapis do rastreio, o codigo;
   - clique no codigo de rastreio para abrir a pagina dos Correios com ele preenchido.
5. Bolinhas nos dias: verde = finalizados, amarelo = em aberto.

Outros botoes:
- Vendedores / Periodo / busca: filtram a tabela.
- Refazer planilha do dia: grava de novo a planilha do dia com o que esta no historico.
- Exportar Excel: salva o que esta filtrado na tela.
- Exportar tudo...: salva todas as tabelas (Ano / Mes / Dia) numa pasta que voce escolher.
- Importar pasta: le tabelas TOTVS antigas e completa cliente e status.

PASTA DOS DADOS (SERVIDOR)
--------------------------
O arquivo configuracao.json, ao lado do .exe, diz onde ficam os dados. Hoje aponta para
a pasta do servidor (\\servidor\Dados\Logistica\...\ITU), entao todos que abrirem este
programa veem e editam o mesmo historico. Varias pessoas podem usar ao mesmo tempo;
a tela se atualiza sozinha a cada 15 segundos.

Para usar outra pasta: botao "Trocar pasta..." no topo da tela.
Se apagar o configuracao.json, o programa usa uma pasta "Saida" ao lado do .exe.

Nao apague o arquivo historico_itu.json da pasta dos dados: e ele que guarda tudo.

RASTREIO AUTOMATICO PELOS CORREIOS (opcional)
---------------------------------------------
Veja "COMO CONFIGURAR A API DOS CORREIOS.txt". Sem configurar, o resto funciona normal.
O correios_config.json nao vai para o GitHub (tem a senha). Deixe uma copia dele na pasta
dos dados do servidor: todos os computadores instalados usam essa.

PUBLICAR UMA VERSAO NOVA (quem mexe no codigo)
----------------------------------------------
1. Altere o codigo em _codigo-fonte.
2. Rode _codigo-fonte\gerar_exe.bat (precisa de Python e do Inno Setup 6). Ele gera o .exe,
   o instalador\Instalar Controle Correios Itu.exe e o versao.txt com a data e hora.
3. De commit e push. Os programas instalados avisam na proxima vez que abrirem.

PASTAS DO REPOSITORIO
---------------------
instalador\ ................. o instalador (e o que os computadores baixam para atualizar)
configuracao.json ........... aponta para a pasta dos dados no servidor
Modelos\ .................... Modelo de Tabela TOTVS usado para gerar as planilhas
_codigo-fonte\ .............. codigo do programa, so para quem for alterar
